Documentation

Multi-provider AI app — reports, chat, dual chat, RAG knowledge bases, on-device LLM and embedder, share-target ingest, fan-out / fan-in, and worker-judged batches (Tournament / Judges / Compare / Rank-the-translators).

Kotlin 2.4.0 · Jetpack Compose · ~161,212 LOC across 406 Kotlin files · 91 cloud providers across four API formats (OPENAI_COMPATIBLE / ANTHROPIC / GOOGLE / REPLICATE) · 12 external metadata repositories layered into one resolved (provider, model) pricing + capability view.

Reading order
