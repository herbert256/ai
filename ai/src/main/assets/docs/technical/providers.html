Catalog & registry

The catalog is one JSON file per provider under assets/providers/ — 91 files, each a bare ProviderDefinition object (no {"providers": [...]} wrapper, no top-level version). It is not hardcoded in Kotlin. ProviderRegistry is a mutable object that starts empty on a fresh install; importFromAsset reads every *.json file (sorted by filename, deterministic merge; a malformed file is skipped rather than fatal) and persists the result to the provider_registry SharedPreferences file as a list of ProviderDefinition JSON objects.

Registry surface (all on ProviderRegistry)
  • getAll / findById / findByHost — the latter resolves a request hostname to its provider via a hostIndex rebuilt on every save() from baseUrl + auxHosts (first claimant wins on collision); ProviderThrottle uses this to find per-provider overrides.
  • add (refuses duplicate ids), update (bumps per-field ProviderFieldTimestamps), remove.
  • importFromAsset — append-only, skips ids already present.
  • syncFromAsset — refreshes only the asset fields the user hasn’t hand-edited (timestamp still null) and never appends new providers.
  • upsertFromJson — replace-by-id-or-append; this is the user-import path and still expects a top-level {"providers": [...]} wrapper.
  • resetToDefaults / restartFromAsset — wipe + re-seed from the bundled asset files.

AppService is intentionally not a Kotlin data class: its equals / hashCode / toString are id-only (two services are equal iff their ids match), and it hand-writes a copy(...) funnel covering all 41 fields so a newly added field can’t be silently dropped on update. The synthetic AppService.LOCAL (id = "Local", baseUrl = "local://") is declared in the companion object, is not in the registry, and routes to the on-device runtime instead of Retrofit.

Identity & defaults

The id-unification refactor collapsed the legacy displayName and prefsKey fields into id. The UI shows id directly; SharedPreferences key prefixes use id directly (e.g. OpenAI_api_key); id is also the human-readable picker label.

Defaults — apiFormat = OPENAI_COMPATIBLE, modelsPath = "v1/models", chat path "v1/chat/completions", seedFieldName = "seed", modelListFormat = "object", every Boolean flag false, every throttle override null (inherit the global default).

Almost every bundled provider explicitly writes defaultModelSource = "API" even though the field defaults to null and behaves identically when absent — entries below only call it out when a provider differs. Where a provider declares litellmPrefix, the LiteLLM lookup key is <litellmPrefix>/<modelId>. Where it declares openRouterName, the OpenRouter key is <openRouterName>/<modelId>.

typePaths holds the per-model-type API paths a provider exposes, keyed by the ModelType string constants ("chat", "responses", "embedding", …); almost every entry only declares "chat". There is no separate stored chatPath / responsesPath / endpointRules — those are computed getters on AppService that walk a fallback chain: per-provider override → user-supplied global default (AI Setup → Model Types) → built-in default. Chat-vs-Responses routing for OpenAI is decided at dispatch time by pattern lists, not by any stored routing table.

91 providers total — 88 OPENAI_COMPATIBLE, 1 ANTHROPIC (Anthropic), 1 GOOGLE (Google), 1 REPLICATE (Replicate). All 88 OpenAI-compatible providers share the unified dispatch path; only Anthropic, Google and Replicate carry format-specific code.

OPENAI_COMPATIBLE (default, standard Authorization: Bearer), ANTHROPIC (Claude /v1/messages shape with x-api-key + anthropic-version headers and a required max_tokens), GOOGLE (Gemini :generateContent path-style with the key appended as a ?key= query param, not a header), REPLICATE (async predictions API, chat models only).
typePaths
Per-model-type API paths overriding the global defaults. Most providers only override chat; a few (DeepInfra) also override embedding.
modelsPath
GET path for the model-list endpoint, relative to baseUrl. Default v1/models.
seedFieldName
Name of the seed field in the request body. Mistral is the only bundled provider that calls it random_seed; everyone else uses seed.
supportsCitations / supportsSearchRecency
Provider returns inline citations / accepts a search_recency parameter (Perplexity is the only bundled provider setting either).
extractApiCost
Provider's response includes a per-call cost field (OpenRouter); the dispatch layer extracts it instead of computing from tokenUsage × unitPrice.
costTicksDivisor
Provider returns cost in ticks rather than dollars (xAI uses 10¹⁰). Provider-config edit refuses non-positive values.
promptTokensIncludeCachedTokens
Whether OpenAI-compatible prompt_tokens already includes cache reads. Defaults to true; xAI sets false because it reports cache reads in a separate flattened cached_tokens field while leaving prompt_tokens as the fresh-token bucket.
modelListFormat
object (default — wrapped in { "data": [...] }) vs array (Together, Google, GitHubModels all return a bare top-level array).
modelFilter
Regex applied to model ids during listing — trims internal / test / preview models out of a noisy catalog.
litellmPrefix / openRouterName
Composite-key prefixes for the corresponding pricing tier — see costs and repositories.
hardcodedModels
Fallback list shown when no /models endpoint is available, defaultModelSource = MANUAL (no bundled provider currently sets this), or to reinstate documented-but- unlisted endpoints. With mergeHardcodedModels = true the list is unioned with the live API list on refresh instead of replacing it.
defaultModelSource
"API" or "MANUAL"; null behaves as "API". Determines whether the app fetches a live list or shows the hardcoded fallback.
defaultInactive
When true, the bootstrap seeds providerStates[id] = "inactive" the first time the provider is seen, so it ships visible in pickers but disabled until the user explicitly flips it on. No bundled provider currently sets it — StepFun did before the keyless-provider sweep, but was dropped.
nativeRerankUrl / nativeModerationUrl / nativeCapabilityUrl
Full URLs the rerank / moderation / capability dispatchers POST to instead of building a chat fallback. nativeRerankUrl is set on SiliconFlow and Cohere; nativeModerationUrl on Mistral; nativeCapabilityUrl on Cohere. Everyone else falls through to a chat-prompt fallback.
pricingFromModelList (Together)
Provider's /v1/models block carries authoritative pricing — harvested into the TOGETHER tier on every refresh, beating every curated catalog and the manual override for Together calls.
crossProviderModelList (OpenRouter)
Provider's /v1/models drives pricing + type fan-out across other providers — the OpenRouter tier is both OpenRouter's own self-report and the final cross-provider fallback in PricingCache.getPricing for every other caller.
mergeHardcodedModels
Union persisted hardcodedModels with the API list when the fetcher refreshes — so OpenAI's moderation / TTS / image models and DeepSeek's two pinned ids survive a /v1/models call that doesn't enumerate them. Set on most of the cross-provider aggregators too, so their curated fallback list survives a flaky catalog fetch.
externalReasoningSignalUntrusted (xAI)
Ignore the LiteLLM / models.dev "is reasoning" signal because xAI's always-on reasoning variants reject the reasoning_effort parameter even though they reason internally. The 🧠 badge still renders; only the parameter is suppressed.
responsesApiPatterns · reasoningModelPatterns · reasoningEffortAcceptPatterns · webSearchModelPatterns · adaptiveThinkingPatterns
Lists of ModelPattern: per-id pattern matchers that gate dispatch routing (Responses API), feature badges (🧠, 🌐), the reasoning_effort parameter, and Anthropic's adaptive-thinking shape. A pattern takes exact, prefix, contains, suffix, or regex (all matched against the lowercased model id); when more than one is set they must all match, and an all-null pattern never matches.
maxTokensDefaults (Anthropic, AtlasCloud)
[{ pattern: ModelPattern, maxTokens: Int }] — per-family default max_tokens when the user hasn't pinned one. First match wins; falls back to 4096.
builtInEndpoints
Bundled alternate endpoints (OpenAI Chat Completions + Responses, DeepSeek main + Beta/FIM, Mistral Chat + Codestral, Z.AI Chat + Coding). User picks one on the provider edit screen.
auxHosts (Cohere)
Alternate API hostnames besides the baseUrl host. The rate-limit-retry interceptor and tracer use findByHost to keep aux-host calls grouped under the same logical provider.
Throttle overrides
maxCallsPerProviderPerMinute, maxConcurrentCallsPerProvider, maxRetriesOn429, retryBackoffMs429, maxRetriesOn529, retryBackoffMs529 — per-provider caps overriding the global NetworkSettings defaults (60 calls/min, 5 concurrent, 3 retries, 1000 ms backoff); null inherits. See throttle.

Activation gating

Setting an API key on a provider isn't enough to mark it active. When the user flips a provider on, the activation gate runs both a /models fetch and an API-key test against the default model; both must succeed before the state flips to "ok" and the default agent is created. Either failure leaves the provider in "error" state with no agent created.

The four provider states (providerStates[id], persisted under the provider_states prefs key):

ok
Models fetch + key test both passed; default agent created.
error
Key set but activation failed one of the two checks.
inactive
User explicitly disabled the provider (or a defaultInactive provider's first bootstrap).
not-used
No key configured, or the key was cleared.

Refresh-all surfaces failed providers with a one-tap nav-to-edit so the user can fix bad configurations without hunting.
